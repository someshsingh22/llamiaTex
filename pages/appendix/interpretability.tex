Three baselines are compared: (i) random-projection baseline (same dimensionality, Gaussian initialization), (ii) raw agent-side representation $\vh_s$ before projection, and (iii) LLAMIA-Verb's hidden states extracted from the final transformer layer at the position where the engine output is consumed.

LLAMIA-Verb's hidden states achieve lower probe accuracy than $\vz_s$ on every concept, including material balance ($91.8\%$ vs $94.2\%$). The gap is smallest for material balance, consistent with this concept being partially recoverable from verbalized text (piece counts and evaluation scores).

% \subsection{Instruction Modulation of Latent Representations}
% \label{sec:app_interp_modulation}

% For each of five ICP instruction themes (Endgames, Pawn Structures, Tactical Blunders, Piece Coordination, Repetition), we collect $N{=}200$ position pairs: the same position processed by LLAMIA with and without the instruction. Note that the projected tokens $\vz_s = H_\varphi(G_\psi(s))$ are instruction-invariant: the subagent does not receive the instruction text. The modulation we measure occurs in the LLM's hidden states at the $\vz_s$ token positions, where instruction context from preceding language tokens influences how the LLM contextualizes the latent input. We define $\Delta\vz_s = \vh^{\text{instr}}_{[\vz]} - \vh^{\text{base}}_{[\vz]} \in \R^{k \times e}$, the difference in LLM hidden states at the latent-token positions, and measure the linear separability of the instruction-present vs.\ instruction-absent conditions using a logistic classifier trained on $\Delta\vz_s$.

% Table~\ref{tab:modulation} reports the linear separability (measured as the AUC of a logistic classifier trained on $\Delta\vz_s$). All five instruction themes produce separable shifts significantly above chance (permutation test, $p < 0.001$ for each theme), confirming that natural-language instructions modulate the projected latent representation. The modulation is strongest for Pawn Structures (AUC $= 0.91$) and weakest for Repetition (AUC $= 0.72$), matching the order of ICP motif acquisition during training (Section~\ref{sec:app_results_icp_motif}).

% \subsection{Activation Patching}
% \label{sec:app_interp_patching}

% We apply activation patching~\cite{jenner2024evidence} to locate which of the $k$ projected token positions carry decision-relevant information. The procedure follows \citet{jenner2024evidence}: given a pair of positions $(s_{\text{clean}}, s_{\text{corrupt}})$ where BT4's top move changes but T72's (a weaker Lc0 network, $\sim$2000 Elo without search) does not---thereby isolating the superhuman planning signal---we patch individual token positions from the clean to corrupt latent representation and measure the effect on LLAMIA's output logits.

% \paragraph{Setup.} We construct 500 (clean, corrupt) pairs by finding positions where BT4's top-1 move differs from T72's top-1 move, and the two positions share the same material configuration but differ in piece placement on 1--3 squares. We patch each of the $k{=}32$ token positions independently and measure the KL divergence between the patched and clean output distributions.

% \paragraph{Results.} Token positions 1--4 carry the majority of the decision-relevant signal, accounting for 72\% of the total patching effect. Positions 5--8 contribute 18\%, and positions 9--32 contribute the remaining 10\%. This concentration is consistent with the token-count ablation (Table~\ref{tab:abl_tokens}), where $k{=}4$ retains substantial performance: the projector learns to front-load the most important features into the first few token positions.

% The patching effect is largest for positions involving long-range tactical motifs (discovered attacks, pins along diagonals) and smallest for positions where the positional evaluation is clear from material alone. This is consistent with the linear-probe results: the information that most distinguishes LLAMIA from verbalized baselines is the fine-grained tactical and positional structure that resists text serialization.

% \subsection{Feature-Delta Analysis ($\pi$ vs.\ $\pi'$)}
% \label{sec:app_interp_delta}

% We decompose the representation shift $\Delta\vz_s$ between different operating conditions on a fixed set of 100 positions: (i) base LLAMIA vs.\ ICP-instructed LLAMIA, (ii) base LLAMIA vs.\ Maia-conditioned LLAMIA (Behavior Cloning at target Elo 1300 vs.\ 1900), and (iii) base LLAMIA vs.\ LLAMIA-Verb on the same positions.

% For each pair, we compute the top-10 principal components of $\Delta\vz_s$ and project them into the concept-probe basis. The analysis reveals that ICP instructions and Maia conditioning produce \emph{sparse, interpretable} shifts: ICP-Endgame shifts load primarily on the game-phase and pawn-structure probes, while Maia-1300 conditioning shifts load on the piece-activity and tactical-motif probes (encoding the tendency of lower-rated players to leave pieces passive and miss tactical patterns).

% By contrast, the LLAMIA-full vs.\ LLAMIA-Verb shift is dense and distributed across all concept dimensions, consistent with the latent channel providing uniformly richer information rather than a single missing feature. This supports the view that verbalization is not missing one specific signal but rather introducing a uniform compression loss across the full representation.
