\subsection{Frontier LLMs with Verbalized Tools}
\label{sec:app_baseline_frontier}
% =============================================================================

To select the strongest frontier baseline, we evaluate five
models---GPT-5.1~\cite{XXXgpt51}, Claude Sonnet~4.5~\cite{XXXsonnet45},
Claude Opus~4.5~\cite{XXXopus45}, Gemini~2.5~Pro~\cite{XXXgemini25}, and
Qwen3-235B~\cite{XXXqwen3}---each given access to Lc0-BT4 via a
ReAct~\cite{yao2022react} tool-calling loop.
At each invocation the tool returns the top-5 moves with centipawn
evaluations, win/draw/loss probabilities, and principal variations up to
depth~20.
All models share identical tool schemas, system prompts, and sampling
parameters; the only variable is the LLM backbone.
We sample 100~positions from each LLAMIA-Bench task and report the
aggregate metric per task group.

\subsection{LLAMIA-Verb-RL}
\label{sec:app_baseline_verb}
% =============================================================================

LLAMIA-Verb-RL is the primary controlled ablation of LLAMIA.
It receives the identical base model, training data, reward signals, and RL
recipe (DAPO) as LLAMIA, but the subagent's output is provided exclusively
through verbalized tool responses: top-$k$ moves, centipawn evaluations, WDL
probabilities, and principal variations rendered as text tokens.
No LatentBridge projection is trained; the continuous latent
tokens~$z_S$ that LLAMIA receives are replaced by their textual equivalents.

We train LLAMIA-Verb-RL at three scales---4B, 8B, and 14B---matching the
corresponding LLAMIA checkpoints in base model architecture, training data,
and total compute budget.
This controlled setup isolates the contribution of latent state
internalization from model family, data mix, reward shaping, and
optimization, and directly tests the central claim that verbalization is a
lossy bottleneck (\cref{sec:experiments}).

\subsection{Lc0 Architecture Cross-Check}
\label{sec:app_baseline_lc0}
% =============================================================================

To verify that internalization generalizes across agent architectures, we
repeat key evaluations replacing BT4 with weaker Lc0 networks spanning
approximately 2000--2600~Elo.
All ratings are measured \emph{without search} (single forward pass,
policy-only decoding) using our gauntlet protocol
(\cref{sec:app_bench_gameplay_elo}).
We emphasize the without-search criterion because LLAMIA internalizes the
agent's single-forward-pass representation via the LatentBridge; the
computational budget spent during tree search is not distilled into the
latent state, so the no-search rating reflects the information available to
internalization.

Table~\ref{tab:lc0_crosscheck} lists the networks.
The set spans three architectural families---convolutional SE-ResNets
(T72, T78), standard transformers (T80, T82), and big transformers
(BT3)---to separate the effect of network architecture from raw capacity.
BT4 is included as the primary agent for reference.
