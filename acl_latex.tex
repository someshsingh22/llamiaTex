\begin{abstract}

% LLMs are now routinely deployed as orchestrators that delegate to
% specialized subagents, and that delegation is mediated in natural
% language. This default works when the subagent is itself an LLM. It
% breaks down in domains where the strongest agents are not language
% models: chess engines, robot policies, and autonomous-driving stacks
% encode their expertise in latent representations of policy, value, and
% learned features rather than in words. Connecting such an agent to an
% LLM currently requires verbalization, with each interaction step
% compressing a continuous representation into a short textual summary.
% We ask whether this textual interface is adequate when the collaboration
% has to survive multiple steps or carry signals that resist serialization.
% We answer the question on LLAMIA-Bench, six collaborative chess tasks
% covering behavior cloning, stylometry, puzzle understanding, and
% commentary. No task is solvable by the LLM or the engine in isolation,
% and the suite is constructed so that the fraction of task-relevant
% signal preserved by verbalization varies across tasks. Against this
% benchmark we propose latent state internalization. A learned projector
% maps the subagent's continuous representation into the LLM's token
% stream as state tokens, and the projection is re-issued whenever an
% action advances the environment so the LLM always reasons over the
% current state.
% A single 14B model trained this way, LLAMIA, matches or exceeds
% task-specific finetunes and GPT-5.1 with tool access on every category
% of LLAMIA-Bench. The gap between internalized and verbalized
% integration, which we call the verbalization debt, grows with the
% number of interaction steps and does not close as the LLM scales from
% 4B to 14B parameters. LLAMIA also holds up out of distribution on
% boards where task-specific finetunes collapse.

  LLMs are increasingly deployed as orchestrators that coordinate specialized subagents
  to solve complex tasks through natural language. However, in many important domains like game playing and robotics
  the strongest available agents are not language models. Integrating non language agents with LLMs would require \emph{verbalization} or compressing their rich continuous representations into sparse textual summaries at each interaction step.
  To study whether verbalization constitutes a bottleneck, we introduce \textsc{LLAMIA-Bench}, a suite of six collaborative chess tasks spanning three facets: behavioral imitation, state assessment, and natural-language explanation. Tasks are drawn from prominent problems in chess literature and industry, each unsolvable by either component alone, and selected to vary in how much relevant signal survives verbalization.
  Our experiments reveal a consistent \emph{verbalization debt}: the performance gap between verbalized and internalized integration widens throughout training and persists as the LLM scales from 4B to 14B parameters. To close this gap, we introduce \emph{latent state internalization}, which projects the subagent's continuous representations directly into the LLM's token stream as learned state tokens, with dynamic re-encoding as actions advance the environment state. A single 14B model,
  \textsc{LLAMIA}, trained under this paradigm matches or exceeds dedicated task specialists and frontier models including GPT-5.1 with tool access across all benchmark tasks, and generalizes out-of-distribution where task-specific finetunes collapse.
  \end{abstract}

\section{Conclusion}
\label{sec:conclusion}
\vspace{-2mm}
We introduced latent state internalization, an LLM--agent integration method that replaces verbalized communication with direct projection of the agent's continuous representations into the LLM's embedding space. A single LLAMIA-14B, trained via projector alignment followed by DAPO, matches or exceeds dedicated task finetunes across \textsc{LLAMIA-Bench}. The verbalization debt widens with \somesh{Need to check this}interaction depth and on signals that resist text serialization (e.g., puzzle interest), and does not close with LLM scale or RL budget in our evaluated range, establishing verbalization as a structural bottleneck for LLM--agent collaboration.
